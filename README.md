# 🎭 Mafia UZ — игровая Мафия в Telegram

Бот-ведущий игры «Мафия» для узбекскоязычной аудитории (🇺🇿 + 🇷🇺).

**Бот:** [@mafiauzs_bot](https://t.me/mafiauzs_bot)

## Как играть
1. Добавьте бота в группу
2. `/start` → лобби → все жмут «➕ Qoʻshilish»
3. Создатель жмёт «▶️ Oʻyinni boshlash» (от 4 игроков, без лимита)
4. Роли приходят в личку: Дон, Мафия, Комиссар, Доктор, Мирные
5. Ночи, дни, голосование — ведёт бот, с таймерами

## Система (как у топ-ботов, уникальная)
- 👤 **Профили**: карточка `/me` — уровень, титул, XP, рейтинг, монеты
- 🎖 **Уровни и титулы**: от «Yangi oʻyinchi» до «Mafiya Doni»
- ⭐ **Рейтинг**: 1000 база, ±за победу/поражение, серия побед даёт бонус
- 🪙 **Танга (монеты)**: за игры, победы, серию дней
- 🎁 **Ежедневный бонус** в личке: 10–30 монет, стрик дней
- 🏆 **TOP-10 по рейтингу**: `/top` в группе
- 🏅 **12 достижений**: первая победа, серии, спасения доктором, точные проверки комиссара, победы Доном
- 📊 Личный итог каждой игры приходит в ЛС с обновлённой карточкой

## Роли
- 🎯 Дон / 🔪 Мафия — выбирают жертву ночью
- 🕵️ Комиссар — проверяет игрока каждую ночь
- 💊 Доктор — спасает игрока (можно себя)
- 👤 Мирные — ищут мафию днём

## Инфраструктура ($0, работает вечно)
- Поллинг-эстафета GitHub Actions: ран сам запускает себе замену (cron */5 как страховка)
- Состояния игр — зашифрованные файлы (AES-256-GCM) в папке `games/` этого репозитория
- Никаких платных сервисов

## Файлы
- `bot.js` — игровой движок (zero-dependency, Node 20+)
- `test.js`, `test2.js` — headless-тесты полной партии и таймеров
